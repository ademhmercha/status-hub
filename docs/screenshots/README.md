# Captures d'écran à produire

Faites tourner l'application en local (voir le README racine), avec le moniteur de démo et une panne simulée, puis enregistrez ici (PNG, ~1280 px de large, thème clair) :

| Fichier | Contenu |
|---|---|
| `dashboard.png` | tableau de bord avec 3 ou 4 moniteurs, dont un en panne, et le panneau de démo |
| `monitor.png` | détail d'un moniteur : cartes de disponibilité, graphique de latence p50/p95, barre de 90 jours, incidents |
| `status-page.png` | page publique `/status/<slug>` avec une panne partielle en cours |

Le schéma d'architecture est à placer dans `docs/architecture.png`.
